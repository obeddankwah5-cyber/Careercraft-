GHANA BUS SIMULATOR — V34 ANDROID DEBUG BUILD

V34 adds a mobile debug panel:
- Tap DEBUG at the bottom-right.
- View captured JavaScript errors and warnings.
- View approximate FPS, screen size and online status.
- Copy a diagnostic report and paste it into your ChatGPT conversation.
- Clear the log or add a sample warning to test the report UI.

HOW TO TEST ON ANDROID
1. Extract this ZIP.
2. Open index.html in Chrome with internet access.
3. Drive the game normally.
4. If something breaks, tap DEBUG → COPY ERROR REPORT.
5. Send the report plus a screenshot and describe what you were doing.

NOTE
This is a browser prototype, not an APK or final Unreal Engine game. It uses Three.js from jsDelivr and needs internet. Browser error capture cannot detect every gameplay/physics issue; screenshots and clear descriptions remain useful. FPS is approximate. No automated cloud upload or remote telemetry is used.
